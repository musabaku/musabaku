## How I use AI for engineering

I use coding agents aggressively, but I do not treat generated code as verified code.

My normal workflow is:

**requirements → repository/schema inspection → implementation → independent review → focused tests → regression checks → release verification**

For difficult changes I use multiple agents/models adversarially: one can implement while another searches for broken assumptions, missing edge cases, unsafe migrations, or false success signals. I remain responsible for the requirements, technical judgment, acceptance criteria, and final verification.

This is particularly useful for **AI-generated or “vibe-coded” applications that need to become maintainable production systems**.
